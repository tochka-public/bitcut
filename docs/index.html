Global index  

One entry per INDEXW bytes of the old document, first occurrence only. Building it costs a full pass over the base — which is exactly why it is the last tier and not the first.

Drift cache

Drift 0 is always tried first, before anything remembered. The rest are kept most-recent-first, SLOTS of them.

The constants are scaled down so the steps are visible on a 70-byte document. The threshold for building the global index is relaxed here too (3× the size of the base). The real rule is stricter: the index is built as soon as one more round of local searching would cost as much as indexing the base outright — which, on 70 bytes, is immediately, because indexing 70 bytes is free.
